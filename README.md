# OneMore

**A tool contains some useful tools. More than one!**

OneMore is a desktop toolbox built with PyQt6. It brings commonly used Android, Qualcomm and MediaTek debugging utilities together in one application, with support for installing tools through the built-in plugin market.

## 来源与致谢

本项目 fork 自 [https://github.com/miniLQ/onemore](https://github.com/miniLQ/onemore)。

感谢原项目 owner [miniLQ](https://github.com/miniLQ) 的开源工作和项目基础。

## 功能

- 集成多种 Android、Qualcomm 和 MediaTek 工具
- 通过插件市场安装和管理工具
- 支持插件独立更新
- 支持中英文界面
- 支持 Windows 桌面环境

## 运行

需要 Python 3.10 或更高版本。

```bash
pip install -r requirements.txt
python main.py
```

首次启动后，可以在插件市场中安装需要的工具。安装插件后请重启 OneMore，使插件生效。
